# defragment_large_collection: repeated PIT-history migration conflict

PSMDB 9.0.4-1; sharding; test: defragment_large_collection.js.

**Failure:** defragmentation cannot complete before the internal assertion deadline. The balancer repeatedly rejects a migration because it would drop point-in-time reachable ownership history for a partially overlapping chunk, then reconstructs the same defragmentation phases.

**Evidence:** reproduced once with WiredTiger cache 0.25 GB. This is a repeated migration conflict, not proof of insufficient cache. No larger-cache or escape-hatch control was run.

**Required investigation:** make the defragmentation/migration policy converge while preserving recipient PIT history. Review overlap reconciliation and cluster-time advancement. Fixture defaults already reduce recipient history retention to one second; proposing that value again is not a fix.

Do not globally enable allowMigrationsToDropRecipientPITHistory: it changes PIT-read guarantees. A larger outer test timeout does not resolve the demonstrated conflict.

**Status:** remains enabled; no verified source fix.
