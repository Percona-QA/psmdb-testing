# FCBIS tests in multiversion replica-set suites

Environment: PSMDB 9.0.4-1.

`jstests/replsets/fcbis-replication.js` in `replica_sets_last_lts` — **Percona-specific test annotation defect** — the test requires file-copy-based initial sync followed by promotion and a successful write. The suite randomly selects latest or last-lts binaries for replica-set members. This introduces cross-version physical WiredTiger file copying into a test intended to verify FCBIS replication behavior, rather than mixed-version compatibility. The current implementation checks source FCBIS capability and rejects a source binary newer than the destination in `src/mongo/db/repl/initial_sync/initial_syncer_fcb.cpp`.

## Required PSMDB test change

Add `multiversion_incompatible` while preserving the existing storage requirement:

```javascript
 * @tags: [requires_wiredtiger, multiversion_incompatible]
```

The `replica_sets_multiversion_selector` override in `buildscripts/resmokeconfig/matrix_suites/overrides/multiversion.yml` already excludes this tag. No FCV-specific tag or enterprise-module tag is needed: the restriction concerns the mixed-binary scenario, and FCBIS is a Percona implementation.

`jstests/replsets/fcbis_backup_cursor_extend.js` is the companion Percona test. It verifies that FCBIS extends its backup cursor when cloning falls behind, using `fileBasedInitialSyncMaxLagSec` and `initialSyncHangAfterCloningFiles`. Its current tags already contain `requires_wiredtiger` and `multiversion_incompatible`; preserve them. The additional FCBIS tests currently present (`fcbis_storage_metadata_fetch.js`, `fcbis_busy_backup_cursor_fallback.js`, and `fcbis_unclean_shutdown.js`) also already carry `multiversion_incompatible`.

Static inspection only; no test was run and no failure log was supplied. This identifies a Percona-related test-selection/configuration defect: the test belongs to the Percona FCBIS implementation and is absent from the matching local mongo checkout. It does not establish a defect in the FCBIS server implementation.
