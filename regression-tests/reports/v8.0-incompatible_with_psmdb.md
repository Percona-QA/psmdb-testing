## Potential PSMDB and percona-mongot bugs

### Tests

- `mongos_standby_all_commands.js` in `no_passthrough` — **Percona command-map correction validated locally** — The auditGetOptions entry was backported from 8.3. One focused run passed on PSMDB 8.0.38-16, including both dedicated-config-server and config-shard branches.

- `validate_interrupt.js` in `percona_no_passthrough_with_mongod` (inMemory) — **Percona test timing correction validated locally** — Adaptive maxTimeMS calculation and verification of an interrupt after validation starts were backported from 8.3. One focused inMemory run passed on PSMDB 8.0.38-16; validation started and was interrupted with MaxTimeMSExpired.

## Disabled: established reasons

### Suites

- `*_ese*` — **Missing encryption helper** — The suite configuration supplies src/mongo/db/modules/enterprise/jstests/encryptdb/libs/ekf2, which is absent. Percona TDE suites use their own available keys and are retained.

- `*fuzzer*`, `jstestfuzz*` — **Unavailable generated corpus** — Requires jstestfuzz/out/*.js generated from the closed https://github.com/10gen/jstestfuzz repository.

- `*last_continuous*` — **Unavailable PSMDB release** — Requires last-continuous 7.3 binaries; PSMDB 7.3 is unavailable and upstream binaries are excluded from this regression.

- `*last_patch*` — **Unavailable previous-patch setup** — Requires previous-release Git tag resolution and mongo*-last-patch binaries; the image has no Git metadata or last-patch provisioning.

- `*with_replica_set_endpoint` — **Special topology outside selected scope** — Requires replica-set endpoint/auto-bootstrap mode with featureFlagAllMongodsAreSharded; outside standard released-binary regression scope.

- `aggregation_column_store_index_passthrough`, `core_column_store_indexes` — **Default-off feature dependency** — Implicit columnstore-index creation requires default-off featureFlagColumnstoreIndexes, not enabled by this suite.

- `benchmarks_*` — **Separate C++ build** — Requires a separate C++ benchmark build.

- `buildscripts_test`, `resmoke_end2end_tests`, `resmoke_validation_tests` — **Infrastructure self-tests** — Python build/resmoke infrastructure self-tests; outside server binary regression scope.

- `change_streams_multitenant_passthrough`, `change_streams_multitenant_sharded_collections_passthrough`, `concurrency_multitenancy_replication_with_atlas_proxy`, `multitenancy_with_atlas_proxy_jscore_passthrough`, `multitenancy_with_mongoq_jscore_passthrough`, `multitenancy_with_mongoq_unsigned_token_jscore_passthrough`, `serverless` — **Atlas/serverless scope** — These suites explicitly enable Atlas/serverless multitenancy or tenant-aware proxy routing. They are excluded from the selected non-Atlas regression scope; this is not a claim that every related implementation is closed or absent in v8.0.

- `concurrency_compute_mode` — **Empty selector** — No tests: selector.roots is empty in the current v8.0 suite.

- `concurrency_replication_for_backup_restore`, `concurrency_replication_for_export_import` — **External-cluster helper** — ExternalFixture helper requires an existing cluster and --shellConnString/--shellPort; not an independently provisioned regression suite.

- `concurrency_sharded_replication_with_balancer_and_config_transitions_and_add_remove_shard` — **Reproduced FSM/background-hook timeout** — The runner waits 90 seconds for hook acknowledgement while ContinuousAddRemoveShard performs shard/config-server transitions. Shard removal took 134.95 seconds in the 9.0 reproduction and caused thread action still in progress. The same acknowledgement protocol is present in v8.0, so the suite is disabled as a known synchronization failure. The reproduction and duration refer to 9.0.

- `cwrwc_wc_majority_passthrough`, `write_concern_majority_passthrough` — **Invalid secondary-read assumption** — Disabled upstream: secondary reads after majority writes require causal consistency; the passthrough makes an invalid read-visibility assumption. The upstream v8.0 tasks are commented out for this reason. [Replication task](https://github.com/mongodb/mongo/blob/v8.0/etc/evergreen_yml_components/tasks/resmoke/server_divisions/durable_transactions_and_availability/tasks.yml), [sharding task](https://github.com/mongodb/mongo/blob/v8.0/etc/evergreen_yml_components/tasks/resmoke/server_divisions/clusters_and_integrations/tasks.yml).

- `ese`, `external_auth_aws`, `external_auth_oidc`, `external_auth_oidc_azure`, `external_auth_oidc_gcp`, `fle`, `fle2_query_analysis`, `sasl`, `sasl_windows_cyrussasl`, `streams`, `streams_kafka` — **Missing selector roots** — Required selector roots are absent: `src/mongo/db/modules/*/jstests/encryptdb/*.js`, `src/mongo/db/modules/*/jstests/fle/*.js`, `src/mongo/db/modules/*/jstests/fle2_query_analysis/*.js`, `src/mongo/db/modules/*/jstests/sasl/*.js`, `src/mongo/db/modules/*/jstests/sasl/sasl_plugins.js`, `src/mongo/db/modules/*/jstests/streams/*.js`, `src/mongo/db/modules/*/jstests/streams_kafka/*.js`, `src/mongo/db/modules/enterprise/jstests/external_auth_aws/*.js`, `src/mongo/db/modules/enterprise/jstests/external_auth_oidc/*.js`, `src/mongo/db/modules/enterprise/jstests/external_auth_oidc_azure/*.js`, `src/mongo/db/modules/enterprise/jstests/external_auth_oidc_gcp/*.js`. No regression tests can be selected.

- `feature_flag_multiversion` — **Harness feature flags** — Its only test requires default-off featureFlagToaster and featureFlagSpoon; this is feature-flag harness validation.

- `libfuzzer` — **Separate instrumented build** — Requires a separate libFuzzer-instrumented C++ build.

- `logging_perf` — **No binary regression coverage** — Logging-infrastructure sleep test has no server regression selector.

- `magic_restore_*` — **Enterprise restore-workflow incompatibility** — These suites use MagicRestoreEveryN, jstests/hooks/magic_restore_backup.js and jstests/hooks/magic_restore.js to exercise the upstream magic-restore protocol. PSMDB backupCursor hooks are a separate implementation; their presence does not establish compatibility with that enterprise workflow. Excluded from the PSMDB 8.0 regression scope.

- `mongot_e2e_*`, `search*`, `vector_search*` — **Unsupported regression scope** — Search/vectorSearch coverage is excluded from the agreed PSMDB 8.0 regression scope because vectorSearch support is not declared for this release. The e2e suites require mongot-localdev; search and vector_search mocked suites use mongotmock. Both groups are disabled, without treating the mocked runner as a real mongot process.

- `mql_model_haskell`, `mql_model_mongod` — **Unavailable model corpus** — Requires the absent mql-model/test/**/*.json corpus and associated model environment.

- `pretty-printer-tests` — **Debugger self-tests** — GDB pretty-printer self-tests require debugger-specific builds; outside released server binary regression scope.

- `replica_sets_configsvr_param_jscore_passthrough` — **Replica-set configuration mismatch** — The suite sets mongod_options.configsvr but does not set replset_config_options.configsvr=true. ReplicaSetFixture derives the replica-set configsvr field only from the latter or auto-bootstrap, so the generated replica-set configuration does not match the config-server process.

- `replica_sets_recordids_replicated_jscore_passthrough` — **Default-off feature dependency** — Blindly enables recordIdsReplicated through set_recordids_replicated.js but requires default-off featureFlagRecordIdsReplicated.

- `rseq_kernel_check`, `rseq_kernel_check_7014` — **Dedicated host-kernel test** — Requires a dedicated Linux kernel/rseq/tcmalloc compatibility environment; Docker shares the host kernel.

- `sdam_json_test`, `server_selection_json_test` — **Missing separately built executable** — The sdam_json_test and server_selection_json_test runners require their matching executables under installDir. Both are absent from the supplied image and need a separate C++ build.

- `ssl_linear_macos` — **Unsupported operating system** — macOS-only certificate-store tests require macOS system trust configuration; regression execution is Linux-only.

- `tla_plus` — **Formal-model checking** — TLA+/Java model checking is outside server binary regression scope and requires /opt/java/jdk11/bin/java plus TLC.

- `unittest_shell_hang_analyzer` — **Infrastructure self-test** — Hang-analyzer infrastructure self-test requires Evergreen/debugger setup; outside server binary regression scope.

- `unittests_*` — **Separate C++ build** — Requires a separate C++ test build; only the base unittests workflow is retained.

- `watchdog` — **Missing FUSE fault-injection environment** — Requires Charybdefs at /data/charybdefs/mongo/control.py and FUSE mount access, absent from the standard regression container.

### Tests

- `1_test_launching_replset.js`, `3_upgrade_replset.js`, `add_invalid_shard.js`, `change_streams_feature_compatibility_version.js`, `change_streams_multi_version_cluster.js`, `change_streams_multi_version_transaction.js`, `change_streams_read_oplog_after_downgrade.js`, `cluster_cardinality_parameter.js`, `cluster_parameters_disabled_correctly_after_downgrade.js`, `collection_validator_feature_compatibility_version.js`, `crash_mongos_against_upgraded_cluster.js`, `do_upgrade_downgrade.js`, `downgrade_replset.js`, `feature_compatibility_version_lagging_secondary.js`, `initial_sync_downgraded_from_latest.js`, `initial_sync_latest_from_downgraded.js`, `initialize_from_old_node.js`, `major_version_upgrade.js`, `rollback_downgraded_to_latest.js`, `rollback_latest_to_downgraded.js`, `rs_endpoint_upgrade_downgrade.js`, `set_feature_compatibility_version.js`, `set_feature_compatibility_version_confirm.js`, `upgrade_downgrade_cluster.js`, `upgrade_downgrade_idempotency.js`, `upgrade_downgrade_sharded_cluster.js`, `view_definition_feature_compatibility_version.js` in `multiversion`, `multiversion_auth`, `multiversion_auth_future_git_tag`, `multiversion_future_git_tag` — **Unavailable PSMDB release** — The tests or their imported upgrade helpers start last-continuous 7.3 binaries. Only PSMDB 7.0 is provisioned as the old release; latest-binary tests that merely set FCV 7.3 are retained.

- `2_test_launching_cluster.js` in `multiversion`, `multiversion_auth`, `multiversion_auth_future_git_tag`, `multiversion_future_git_tag` — **Excluded last-continuous configuration coverage** — The test explicitly includes last-continuous in its mixed-version validation scenario. PSMDB 7.3 coverage is excluded from this regression setup, and the same test is already excluded in the 8.3 list. The 8.0 exclusion follows that version-selection scope; the precise assertion from the reported failure has not been established.

- `cache_correctness_pbt.js`, `index_correctness_pbt.js`, `run_all_plans_pbt.js`, `subplanning_pbt.js` in `replica_sets_jscore_passthrough_last_lts_old_new_new`, `sharding_jscore_passthrough_last_lts_new_old_old_new` — **Mixed-version parameter incompatibility** — The shared runDeoptimized helper in jstests/libs/property_test_helpers/property_testing_utils.js changes internalQueryDisablePlanCache at runtime. PSMDB 7.0.30-16 rejects that change with IllegalOperation, causing the property assertion to fail before a query-result comparison. The same startup-only restriction remains in PSMDB 7.0.48-25. Explicit generator exclusions disable these tests in both suites.

- `dbcheck_old_format_extra_keys_primary.js`, `dbcheck_old_format_extra_keys_record_does_not_match.js`, `dbcheck_old_format_extra_keys_record_not_found.js`, `dbcheck_old_format_extra_keys_secondary.js`, `dbcheck_old_format_keys_basic.js`, `dbcheck_old_format_missing_keys.js`, `dbcheck_old_format_missing_keys_primary.js`, `dbcheck_old_format_missing_keys_secondaries.js`, `fcbis_rolling_upgrade_from_4_0.js` in `multiversion`, `multiversion_auth`, `multiversion_auth_future_git_tag`, `multiversion_future_git_tag` — **Unavailable historical binaries** — dbcheck_old_format_* uses DbCheckOldFormatKeysTest with its default binVersion 4.2. fcbis_rolling_upgrade_from_4_0 explicitly walks 4.0, 4.2, 4.4, 5.0 and 6.0 before newer releases. Those historical binaries are outside the prepared 7.0/latest setup.

- `fle2_range_preview_rename.js` in `multiversion`, `multiversion_auth`, `multiversion_auth_future_git_tag`, `multiversion_future_git_tag` — **Unavailable encryption client** — EncryptedClient from jstests/fle2/libs/encrypted_client_util.js calls assertEnterpriseShell(), which requires buildInfo().modules to contain enterprise. The supplied PSMDB shell has no such module.

- `invalid_wildcard_index_log_at_startup.js` in `multiversion`, `multiversion_auth`, `multiversion_auth_future_git_tag`, `multiversion_future_git_tag` — **Missing exact historical binary** — Explicitly starts binVersion 8.0.16 to create an invalid wildcard index accepted by that revision. The setup provisions latest and mongod-7.0, not mongod-8.0.16; substituting a newer binary would change the scenario.

- `oidc_multipurpose_idp.js` in `multiversion`, `multiversion_future_git_tag` — **Missing enterprise test helpers** — Imports src/mongo/db/modules/enterprise/jstests/external_auth/lib/oidc_utils.js and oidc_vars.js, which are absent from the checkout. The auth suite variants already exclude the test natively; the external tag file also covers it consistently.

- `schema_validator_with_expr_variables.js` in `concurrency_sharded_replication_last_lts_new_old_old_new` — **Mixed-version validator incompatibility** — The workload installs a validator with a dynamic $getField.field expression. The 8.0 primary accepts collMod, but the 7.0.30-16 secondary cannot parse its oplog entry and terminates with fatal assertion 34437 and Location5654600. The remaining run was stopped after the fatal assertion. PSMDB 7.0.48-25 still requires a constant string for $getField.field. An explicit generator exclusion disables this workload in this suite.

- `ssl_fips.js` in `ssl` — **Unavailable FIPS environment** — The Debian 12 build image does not provide the required FIPS environment. The test starts mongod with tlsFIPSMode and is excluded through the ssl_environment_tags.yml setup tag file.
