# PSMDB 9.0.4-1: excluded tests and reasons

The reasons below apply to the stated test configurations. A configuration limitation is not automatically a PSMDB server defect. Detailed reports are linked only where reproduction evidence or further investigation is needed.

### `jstests/change_streams/update_lookup_batching_resume.js`

Resume-token progress can stall when periodic no-ops are deliberately disabled. Prior failing baseline and no-op-enabled control.

Evidence / follow-up: [9.0.4-change_streams_whole_db_secondary_reads_passthrough_v1-update_lookup_batching_resume.md](9.0.4-change_streams_whole_db_secondary_reads_passthrough_v1-update_lookup_batching_resume.md).

Applies to secondary-read change-stream suites that disable periodic no-ops; variants with no-ops enabled are not excluded for this reason.

### `jstests/core/query/computation_hoisting_match_pushdown_pbt.js`

Local-only explain diagnostics run inside transaction wrapping; code 263. Same-test diagnostic-block skip passes.

Evidence / follow-up: [9.0.4-replica_sets_multi_stmt_txn_jscore_passthrough-computation_hoisting_match_pushdown_pbt.md](9.0.4-replica_sets_multi_stmt_txn_jscore_passthrough-computation_hoisting_match_pushdown_pbt.md).

Applies to transaction passthrough, including the inMemory and bulk-write variants; not a blanket passthrough exclusion.

### `jstests/core/query/explain/explain_all_plans_execution_stats.js`

CBR produces zero rejected-plan trial execution statistics that this multiplanner-specific test requires.

Evidence / follow-up: [9.0.4-query_join_optimization_passthrough-explain_all_plans_execution_stats.md](9.0.4-query_join_optimization_passthrough-explain_all_plans_execution_stats.md).

Applies to query_join_optimization_passthrough with CBR/samplingCE.

### `jstests/extensions/extensions_query_stats.js`

Confirmed mongo-shell HMAC uses an empty key due to pointer/length argument evaluation order; temporary exclusion pending shell fix.

Evidence / follow-up: [9.0.4-extensions_standalone-extensions_query_stats.md](9.0.4-extensions_standalone-extensions_query_stats.md).

Applies to extensions_* suites using the affected mongo shell.

### `jstests/extensions/extensions_signature_pub_key_path.js`

`--skipExtensionsSignatureVerification` deliberately omits the public-key path in `buildscripts/resmokelib/extensions/add_extensions_signature_pub_key_path.py`; the test unconditionally expects it. Keep excluded in this signature-skipping setup.

Applies to extensions_* suites that skip signature verification.

### `jstests/multiVersion/genericBinVersion/query-optimization/invalid_wildcard_index_log_at_startup.js`

Test requests exact mongod-8.0.16; current setup prepares only version aliases 7.0/8.0/8.3. Environment prerequisite issue, not a proven server defect.

Applies to self-managed multiversion suites whose setup does not provide exact 8.0.16 binaries.

### `jstests/multiVersion/genericBinVersion/server-security/fle2_string_preview_deprecation.js`

EncryptedClient requires enterprise shell module; PSMDB shell does not provide it.

Applies to multiversion and multiversion_auth, including future_git_tag variants.

### `jstests/multiVersion/genericBinVersion/server-security/fle2_string_search.js`

EncryptedClient requires enterprise shell module; PSMDB shell does not provide it.

Applies to multiversion and multiversion_auth, including future_git_tag variants.

### `jstests/sharding/query/search/internal_search_id_lookup_ddl_concurrency.js`

Missing dependency annotation for default-off `featureFlagSearchOptimizedIdLookup`; the test asserts optimized SBE metrics and zero fallback metrics. Keep excluded with regular default flags; add the dependency tag in PSMDB when fixing test metadata.

Applies when sharding-based tests run with regular default feature flags.

### `jstests/with_mongot/e2e/views/mongot_indexed_views_upgrade_downgrade.js`

percona-mongot query index catalog can still resolve a just-dropped vector index; tested on 1.70.3 and supplied 1.70.5. Pending fork/contract investigation.

Evidence / follow-up: [9.0.4-mongot_community_fixture_e2e_single_node-mongot_indexed_views_upgrade_downgrade.md](9.0.4-mongot_community_fixture_e2e_single_node-mongot_indexed_views_upgrade_downgrade.md).

Excluded only for the percona-mongot fixture suite; the upstream community-mongot comparison passed.

## CBR explain assumptions

In `query_join_optimization_passthrough`, these tests expect multiplanner trial behavior or explain error handling that differs under CBR:

- `explain_winning_plan.js`: expects trial nReturned=101, receives 0.
- `explain_execution_error.js`: expects explain planning to succeed; the intentional sort memory error occurs during plan selection instead.
- `expr.js`: expects the $divide error inside executionStats; explain itself fails during plan selection.
- `find_with_resume_after_param.js`: expects explain to succeed for a missing RecordId; plan selection instead returns KeyNotFound.

Other tests annotated `does_not_support_multiplanning_single_solutions` are filtered for the same declared CBR incompatibility. Their individual failures were not reproduced. [Baseline and control evidence](9.0.4-query_join_optimization_passthrough-explain_all_plans_execution_stats.md).

## Standalone replication requirements

`block_replica_set_writes.js` and other `requires_replication` tests are excluded from `core_high_yielding` because it runs a standalone fixture. Their commands require replica-set behavior; this is not a general PSMDB feature limitation.

## Disabled suite scenarios

- `replica_sets_configsvr_param_jscore_passthrough`: the replica-set configuration lacks configsvr=true, causing error 103 and an unbounded setup retry before tests start. [Investigation](9.0.4-replica_sets_configsvr_param_jscore_passthrough-insert1.md).
- `concurrency_sharded_replication_last_continuous_new_old_old_new`: `ifr_arm_getmore_retry_race.js` blocks find/getMore on old mongos 8.3 and reaches the test timeout; shutdown also becomes problematic. SERVER-133148 / BACKPORT-29703 are related follow-up context, not proof of the exact local C++ cause. [Investigation](9.0.4-concurrency_sharded_replication_last_continuous_new_old_old_new-ifr_arm_getmore_retry_race.md).
- `query_golden_cbr_histogram` and `query_golden_cbr_sampling`: plan_stability golden results differ in plans, estimates and scanned keys/documents; baseline/correctness/performance review is required. [Histogram investigation](9.0.4-query_golden_cbr_histogram-plan_stability.md), [sampling investigation](9.0.4-query_golden_cbr_sampling-plan_stability.md).
- `query_golden_join_optimization` and `query_golden_join_optimization_plan_stability`: excluded by the historical experimental-task policy. The general suite also has historical explain-shape and golden-output failures requiring review; experimental status alone does not establish a defect. [Investigation](9.0.4-query_golden_join_optimization-join_cardinality_estimation_md.md).
- `write_concern_majority_passthrough` and `cwrwc_wc_majority_passthrough`: SERVER-89135; secondary reads after majority writes require appropriate causal-visibility guarantees. The passthrough needs correction or retirement before re-enabling.
- `search`, `search_auth`, `vector_search`, `vector_search_auth` with inMemory: the shared mongot-mock helper restarts shard nodes to set mongotHost, losing inMemory replica-set state. The affected tests lack persistence tags; this is not an inherent inability to execute search algorithms in memory.
- `change_streams_sharding_fsm_*irs*` and `sharding_change_streams_ignore_removed_shards`: ignoreRemovedShards requires default-off featureFlagChangeStreamReaderV2 (SERVER-135099). Pairwise variants have no eligible tests under the regular defaults.
- ESE suites and `ese`: required upstream encryptdb module/tests or ekf2 setup are absent. PSMDB encryption support does not supply those upstream enterprise test helpers automatically.
- `fle`, `fle2_query_analysis`, `sasl`, `sasl_windows_cyrussasl`, `external_auth_aws`, `external_auth_oidc*`: required upstream enterprise test roots are absent.
- `magic_restore_*`: the enterprise hot-backup magic-restore runner is unavailable.
- `query_golden_disagg`, `query_golden_sharding_disagg`: required Atlas disaggregated-storage fixtures/overrides are absent.
- `multitenancy_with_mongoq*`: the required simulate_mongoq serverless override is absent.
- jstestfuzz-derived suites, including aggregation/multiversion, generational, initial-sync, resharding, rollback, update and query-shape fuzzer variants: their generated corpus depends on unavailable 10gen/jstestfuzz.
- `query_correctness_generated_test` and its query-shape variant: required generated corpora reside in unavailable 10gen/query-correctness-tests repositories.
- `concurrency_replication_for_backup_restore` and `concurrency_replication_for_export_import`: ExternalFixture helpers require a separately provisioned cluster and connection string.
- `concurrency_compute_mode`: selector is empty; its workload is disabled under SERVER-112530.
- `feature_flag_multiversion`: only synthetic Toaster/Spoon-flag tests are selected, and those flags are excluded by default.
- last_patch variants: this regression setup represents the first 9.0 release and supplies no previous patch binary.
- `ssl_linear_macos`: depends on the macOS certificate store; the target environment is Linux.
- `rseq_kernel_check*`: requires controlled host-kernel/glibc/rseq conditions (SERVER-121912); Docker shares the host kernel and does not provision the required kernel variants.
- `watchdog`: requires Charybdefs and FUSE mount access unavailable in the standard regression container.
- benchmarks, libfuzzer and additional unit-test groups: require separate C++ build/test workflows; only the base unittests entry is retained.
- buildscripts/resmoke Python tests, pretty-printer tests and query_tester_self_test: test tooling rather than the released server-binary behavior targeted here.
- `logging_perf`: resmoke logging-throughput tooling using YesFixture/sleep_test; no server regression tests are selected without explicit sleep durations.
- `unittest_shell_hang_analyzer`: infrastructure self-test requiring Evergreen/debugger/core-dump behavior; its expected analyzer execution is skipped outside Evergreen.

## Selection requirements

Old-version combinations exclude tests requiring newer FCV/features and unapplied backports. These are version/revision-dependent requirements. inMemory filters persistence, journaling and WiredTiger-specific tests. These restrictions describe the selected version or engine, not universal PSMDB incompatibility.

## Still enabled

`defragment_large_collection.js` remains enabled: its reproduced PIT-history migration conflict requires investigation rather than an unsupported-module exclusion. [Investigation](9.0.4-sharding-defragment_large_collection.md).

`mixed_cluster_roles.js`, `dollar_audit_mixed_version_mongods.js` and `draining_on_FCV_transition.js` were not newly excluded: the preceding source review did not establish incompatibility.
