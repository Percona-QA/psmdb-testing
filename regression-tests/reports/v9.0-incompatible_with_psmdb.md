# PSMDB 9.0.4-1: regression exclusions and investigations

Reasons apply only to the stated configurations.


1. [Disabled: established reasons](#disabled-established-reasons)
2. [Disabled: further investigation required](#disabled-further-investigation-required)
3. [Enabled: detailed investigation required](#enabled-detailed-investigation-required)

## Disabled: established reasons

- `jstests/change_streams/update_lookup_batching_resume.js`: Resume-token progress can stall when periodic no-ops are deliberately disabled. [Report](9.0.4-change_streams_whole_db_secondary_reads_passthrough_v1-update_lookup_batching_resume.md). Applies to secondary-read change-stream suites that disable periodic no-ops; variants with no-ops enabled are not excluded for this reason.

- `jstests/core/query/computation_hoisting_match_pushdown_pbt.js`: Local-only explain diagnostics run inside transaction wrapping; code 263. Same-test diagnostic-block skip passes. [Report](9.0.4-replica_sets_multi_stmt_txn_jscore_passthrough-computation_hoisting_match_pushdown_pbt.md). Applies to transaction passthrough, including the inMemory and bulk-write variants; not a blanket passthrough exclusion.

- `jstests/core/query/explain/explain_all_plans_execution_stats.js`: CBR produces zero rejected-plan trial execution statistics that this multiplanner-specific test requires. [Report](9.0.4-query_join_optimization_passthrough-explain_all_plans_execution_stats.md). Applies to query_join_optimization_passthrough with CBR/samplingCE.

- `jstests/extensions/extensions_query_stats.js`: Confirmed mongo-shell HMAC uses an empty key due to pointer/length argument evaluation order; temporary exclusion pending shell fix. [Report](9.0.4-extensions_standalone-extensions_query_stats.md). Applies to extensions_* suites using the affected mongo shell.

- `jstests/extensions/extensions_signature_pub_key_path.js`: `--skipExtensionsSignatureVerification` deliberately omits the public-key path in `buildscripts/resmokelib/extensions/add_extensions_signature_pub_key_path.py`; the test unconditionally expects it. Keep excluded in this signature-skipping setup. Applies to extensions_* suites that skip signature verification.

- `jstests/multiVersion/genericBinVersion/query-optimization/invalid_wildcard_index_log_at_startup.js`: Test requests exact mongod-8.0.16; current setup prepares only version aliases 7.0/8.0/8.3. Environment prerequisite issue, not a proven server defect. Applies to self-managed multiversion suites whose setup does not provide exact 8.0.16 binaries.

- `jstests/multiVersion/genericBinVersion/server-security/fle2_string_preview_deprecation.js`: EncryptedClient requires enterprise shell module; PSMDB shell does not provide it. Applies to multiversion and multiversion_auth, including future_git_tag variants.

- `jstests/multiVersion/genericBinVersion/server-security/fle2_string_search.js`: EncryptedClient requires enterprise shell module; PSMDB shell does not provide it. Applies to multiversion and multiversion_auth, including future_git_tag variants.

- `jstests/sharding/query/search/internal_search_id_lookup_ddl_concurrency.js`: Missing dependency annotation for default-off `featureFlagSearchOptimizedIdLookup`; the test asserts optimized SBE metrics and zero fallback metrics. Keep excluded with regular default flags; add the dependency tag in PSMDB when fixing test metadata. Applies when sharding-based tests run with regular default feature flags.

- `explain_winning_plan.js` in `query_join_optimization_passthrough`: expects trial nReturned=101, receives 0.

- `explain_execution_error.js` in `query_join_optimization_passthrough`: expects explain planning to succeed; the intentional sort memory error occurs during plan selection instead.

- `expr.js` in `query_join_optimization_passthrough`: expects the $divide error inside executionStats; explain itself fails during plan selection.

- `find_with_resume_after_param.js` in `query_join_optimization_passthrough`: expects explain to succeed for a missing RecordId; plan selection instead returns KeyNotFound.

- `replica_sets_configsvr_param_jscore_passthrough`: the replica-set configuration lacks configsvr=true, causing error 103 and an unbounded setup retry before tests start. [Investigation](9.0.4-replica_sets_configsvr_param_jscore_passthrough-insert1.md).

- `write_concern_majority_passthrough` and `cwrwc_wc_majority_passthrough`: SERVER-89135; secondary reads after majority writes require appropriate causal-visibility guarantees. The passthrough needs correction or retirement before re-enabling.

- `search`, `search_auth`, `vector_search`, `vector_search_auth` with inMemory: the shared mongot-mock helper restarts shard nodes to set mongotHost, losing inMemory replica-set state. The affected tests lack persistence tags; this is not an inherent inability to execute search algorithms in memory.

- `change_streams_sharding_fsm_*irs*` and `sharding_change_streams_ignore_removed_shards`: ignoreRemovedShards requires default-off featureFlagChangeStreamReaderV2 (SERVER-135099). Pairwise variants have no eligible tests under the regular defaults.

- ESE suites and `ese`: required upstream encryptdb module/tests or ekf2 setup are absent. PSMDB encryption support does not supply those upstream enterprise test helpers automatically.

- `fle`, `fle2_query_analysis`, `sasl`, `sasl_windows_cyrussasl`, `external_auth_aws`, `external_auth_oidc*`: required upstream enterprise test roots are absent.

- `magic_restore_*`: the enterprise hot-backup magic-restore runner is unavailable.

- `query_golden_disagg`, `query_golden_sharding_disagg`: required Atlas disaggregated-storage fixtures/overrides are absent.

- `multitenancy_with_mongoq*`: the required simulate_mongoq serverless override is absent.

- jstestfuzz-derived suites, including aggregation/multiversion, generational, initial-sync, resharding, rollback, update and query-shape fuzzer variants: their generated corpus depends on unavailable 10gen/jstestfuzz.

- `query_correctness_generated_test` and its query-shape variant: required generated corpora reside in unavailable 10gen/query-correctness-tests repositories.

- `concurrency_replication_for_backup_restore` and `concurrency_replication_for_export_import`: ExternalFixture helpers require a separately provisioned cluster and connection string.

- `concurrency_compute_mode`: selector is empty; its workload is disabled under SERVER-112530.

- `feature_flag_multiversion`: only synthetic Toaster/Spoon-flag tests are selected, and those flags are excluded by default.

- last_patch variants: this regression setup represents the first 9.0 release and supplies no previous patch binary.

- `ssl_linear_macos`: depends on the macOS certificate store; the target environment is Linux.

- `rseq_kernel_check*`: requires controlled host-kernel/glibc/rseq conditions (SERVER-121912); Docker shares the host kernel and does not provision the required kernel variants.

- `watchdog`: requires Charybdefs and FUSE mount access unavailable in the standard regression container.

- benchmarks, libfuzzer and additional unit-test groups: require separate C++ build/test workflows; only the base unittests entry is retained.

- buildscripts/resmoke Python tests, pretty-printer tests and query_tester_self_test: test tooling rather than the released server-binary behavior targeted here.

- `logging_perf`: resmoke logging-throughput tooling using YesFixture/sleep_test; no server regression tests are selected without explicit sleep durations.

- `unittest_shell_hang_analyzer`: infrastructure self-test requiring Evergreen/debugger/core-dump behavior; its expected analyzer execution is skipped outside Evergreen.

- `jstests/noPassthroughWithMongod/query/explain/explain_with_backup_plans.js`: In `query_join_optimization_no_passthrough_with_mongod`: the test requires classic multiplanner trial scoring and backup-plan selection, while the suite forces cost-based ranking. Its forceClassicEngine setting does not restore multiplanner ranking. This is a configuration incompatibility identified from code; the test was not executed. [Compatibility and join-costing investigation](9.0.4-1-query_join_optimization_no_passthrough_with_mongod-planner_prerequisites.md).

- `jstests/core/query/resume_query_from_non_existent_record.js`: In `core_minimum_batch_size`: the test expects four remaining documents in an unspecified first batch, but this suite deliberately defaults find batch size to two. Reproduced assertion: expected 2 to equal 4. [Investigation and required PSMDB override change](9.0.4-1-core_minimum_batch_size-resume_query_from_non_existent_record.md).

- `jstests/replsets/initial_sync_replSetGetStatus.js`: In `replica_sets_last_continuous`: secondary 8.3.11-3 interprets initialSync: 2 as a request for full initial-sync statistics, while the test requires the newer summary response. Reproduced failure: missing collectionsToClone. Secondary 9.0.4-1 passes; our list adds the missing backport exclusion. [Reproduction and required PSMDB compatibility fix](9.0.4-1-replica_sets_last_continuous-initial_sync_replSetGetStatus.md).

- `jstests/core/query/doc_validation/doc_validation_invalid_validators.js`: In `replica_sets_jscore_passthrough_last_lts_old_new_new` and `replica_sets_jscore_passthrough_last_continuous_old_new_new`: the old primaries in the reported runs accept a stored validator using $_internalKeyStringValue, but the newer test expects rejection with error 10131412. The missing parser guard was confirmed in the exact 8.3.11-3 source; the user reported the same unexpected-success assertion in both suites. Applicability depends on the old binary revision. [Compatibility evidence and required backport handling](9.0.4-1-replica_sets_jscore_passthrough_multiversion-doc_validation_invalid_validators.md).

- Other `does_not_support_multiplanning_single_solutions` tests in `query_join_optimization_passthrough`: declared CBR incompatibility; individual failures were not reproduced.

- `block_replica_set_writes.js` and other `requires_replication` tests in `core_high_yielding`: the fixture is standalone, but these commands require replication.

- Version/engine selectors: older binaries exclude newer FCV requirements and unapplied backports; inMemory excludes persistence/journaling/WiredTiger requirements. These restrictions are configuration-specific.

## Disabled: further investigation required

- `jstests/with_mongot/e2e/views/mongot_indexed_views_upgrade_downgrade.js`: percona-mongot query index catalog can still resolve a just-dropped vector index; tested on 1.70.3 and supplied 1.70.5. Pending fork/contract investigation. [Report](9.0.4-mongot_community_fixture_e2e_single_node-mongot_indexed_views_upgrade_downgrade.md). Excluded only for the percona-mongot fixture suite.

- `concurrency_sharded_replication_last_continuous_new_old_old_new`: `ifr_arm_getmore_retry_race.js` blocks find/getMore on old mongos 8.3 and reaches the test timeout; shutdown also becomes problematic. SERVER-133148 / BACKPORT-29703 are related follow-up context, not proof of the exact local C++ cause. [Investigation](9.0.4-concurrency_sharded_replication_last_continuous_new_old_old_new-ifr_arm_getmore_retry_race.md).

- `query_golden_cbr_histogram` and `query_golden_cbr_sampling`: plan_stability golden results differ in plans, estimates and scanned keys/documents; baseline/correctness/performance review is required. [Histogram investigation](9.0.4-query_golden_cbr_histogram-plan_stability.md), [sampling investigation](9.0.4-query_golden_cbr_sampling-plan_stability.md).

- `query_golden_join_optimization` and `query_golden_join_optimization_plan_stability`: excluded by the historical experimental-task policy. The general suite also has historical explain-shape and golden-output failures requiring review; experimental status alone does not establish a defect. [Investigation](9.0.4-query_golden_join_optimization-join_cardinality_estimation_md.md).

- `jstests/multiVersion/genericBinVersion/server-security/dollar_audit_mixed_version_mongods.js`: In `multiversion` and `multiversion_future_git_tag`: the user reports missing $impersonatedClient in the first all-latest audit-metadata comparison. The inspected PSMDB code has no call initializing AuditClientAttrs from a normal peer connection, consistent with omission of that block. Cause remains code-supported; no local reproduction. [Audit metadata investigation and required PSMDB fix](9.0.4-1-multiversion-dollar_audit_mixed_version_mongods.md).

## Enabled: detailed investigation required

- `join_costing_invariants.js` in `query_join_optimization_no_passthrough_with_mongod`: two cost checks receive NaN after optimizer fallback; a third finds unequal permutation costs. Investigate planner eligibility and the exact-cost invariant. [Report](9.0.4-1-query_join_optimization_no_passthrough_with_mongod-planner_prerequisites.md).

- `check_async_oplog_sampling_truncates_new_writes.js` in `no_passthrough`: 50 markers but no truncation before the assertion deadline. Pinned oplog/wakeup behavior remains unproven. [Report](9.0.4-1-no_passthrough-check_async_oplog_sampling_truncates_new_writes.md).

- `defragment_large_collection.js` in sharding: repeated migration rejection for recipient PIT-history preservation prevents convergence. No validated fix. [Report](9.0.4-sharding-defragment_large_collection.md).

- `draining_on_FCV_transition.js` in multiversion: prepared transaction starts after the Symmetric-FCV barrier; baseline fails and legacy-FCV control passes. Investigate the correct pre-barrier synchronization point and fix the shared test helper. [Report](9.0.4-1-multiversion-draining_on_FCV_transition.md).
