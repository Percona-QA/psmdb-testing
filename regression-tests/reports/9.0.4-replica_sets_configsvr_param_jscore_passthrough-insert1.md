# Config-server suite: permanent fixture reconfiguration retry

PSMDB 9.0.4-1; suite: replica_sets_configsvr_param_jscore_passthrough; selected test: insert1.js.

**Cause:** mongod starts with --configsvr, but the replica-set configuration omits configsvr:true. Adding the second member returns error 103: “Nodes started with the --configsvr flag must have configsvr:true in their config”. The fixture retries indefinitely; the test and hooks never start. The per-test timeout does not protect setup.

**Evidence:** baseline was stopped after 665 retries. A disposable configuration adding only executor.fixture.replset_config_options.configsvr:true completed in 7.04 seconds; insert1 and all hooks passed.

**Required fix:** add that replica-set option to the maintained suite and bound retries for permanent configuration errors in ReplicaSetFixture._reconfig_repl_set().

**Status:** suite disabled in our list; PSMDB source unchanged.
